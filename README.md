# SolBundler — Solana Bundler for Pump.fun

**[solbundler.app](https://solbundler.app)** — launch tokens on Pump.fun and buy from up to 20 wallets in block 0 via Jito MEV bundles. Before any sniper can react.

## What it does

SolBundler packages token creation and multi-wallet buys into a single atomic Jito bundle. Deploy and initial buys execute together in the same block — or not at all. No gap for snipers to front-run.

- **Block-0 bundling** — up to 20 wallets buy in the same block as token creation
- **Jito MEV bundles** — atomic all-or-nothing execution
- **Non-custodial** — private keys generated and stored in your browser, never touch a server
- **Smart Sell** — coordinated exits across all wallets, chart stays healthy
- **Volume tools, sniper, P&L analytics** — full launch stack in one dashboard
- **No subscription** — flat 1% fee per launch, pay only when you launch
